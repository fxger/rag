## 1. 项目概述

企业级 RAG（检索增强生成）系统，支持多格式文档处理、混合检索（Dense + BM25）、动态权重调整、Cross-Encoder 重排序、高并发单例管理、向量存储和 AI 生成回答。

## 3. 核心架构

### 3.1 高并发单例架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    请求入口 (FastAPI)                            │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│              SingletonManager (单例管理器)                        │
│  • Double-checked locking (双重检查锁)                           │
│  • 线程安全的实例创建                                             │
│  • 统一的生命周期管理                                             │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│           ThreadSafeReranker (线程安全重排序器)                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  Semaphore (max_concurrent=4)                           │   │
│  │  • 控制并发推理数                                         │   │
│  │  • 超时机制防死锁                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  LRU Cache (maxsize=256, ttl=300s)                      │   │
│  │  • 缓存推理结果                                           │   │
│  │  • 减少重复计算                                           │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│           ConnectionPool (连接池)                                 │
│  • Milvus: 2-5连接                                              │
│  • Redis: 5-20连接                                              │
│  • 健康检查 + 自动重连                                           │
└─────────────────────────────────────────────────────────────────┘
```
